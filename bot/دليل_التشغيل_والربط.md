# دليل التشغيل وقواعد فايربيس المحدثة (Firebase & Telegram Setup)

---

## 🔒 1. قواعد أمان فايربيس الرسمية والمحدثة (Firebase Rules)

لحل مشكلة إشعارات التفعيل والسماح لنظام الكاشير والمنتجات بالعمل والمزامنة 100%:

1. افتح **[Firebase Console](https://console.firebase.google.com/)** وافتح مشروعك (`product-manager-5731f`).
2. اضغط من القائمة الجانبية على **Realtime Database**.
3. ادخل على تبويب **Rules** في الأعلى.
4. امسح أي كود قديم، والصق الكود التالي بالكامل ثم اضغط **Publish**:

```json
{
  "rules": {
    "licenses": {
      ".read": true,
      "$licenseKey": {
        ".write": true
      }
    },
    "sales": {
      "$licenseKey": {
        ".read": true,
        ".write": true
      }
    },
    "users_data": {
      "$licenseKey": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

## 🤖 2. تشغيل بوت تليجرام التفاعلي الجديد

البوت تم تحويله بالكامل إلى **لوحة تحكم ذكية بالأزرار** بدون الحاجة لكتابة أوامر نصية معقدة!

### 🚀 خطوات التشغيل:
- اضغط مرتين (Double Click) على ملف: **`تشغيل_البوت.bat`** في مجلد المشروع.
- افتح محادثتك مع البوت على تليجرام واضغط **`/start`**.

### ✨ الميزات الجديدة في البوت:
* **➕ إنشاء كود تفعيل جديد:** تظهر لك أزرار فورية (كود شهر 30 يوم / 3 شهور / سنة / أو تخصيص برقم العميل).
* **📋 قائمة المشتركين:** تعرض لك كروت كل المشتركين مع أزرار مباشرة تحت كل مشترك:
  - 🔄 **تمديد شهر (+30 يوم)** بضغطة زر واحدة.
  - 🛑 **إيقاف وحظر الحساب** لطرده من النظام فوراً إذا تأخر في الدفع.
  - ✅ **إعادة التفعيل**.
* **🔔 إشعارات التفعيل التلقائية:** بمجرد أن يفتح العميل الموقع ويكتب اسمه ورقمه وكود التفعيل، **يصلك إشعار فوري على تليجرام** يحتوي على: (اسم العميل - رقم موبايله - الكود المستخدم - تاريخ انتهاء اشتراكه - أزرار التحكم السريع).
* **📊 إحصائيات النظام:** تقرير لحظي بعدد الأكواد والمشتركين النشطين والمنتهية اشتراكاتهم.
